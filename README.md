# Weather Dashboard

A responsive weather dashboard built with HTML, CSS, and JavaScript. It retrieves current weather conditions and a five-day forecast for searched cities using the Open-Meteo API.

## Features

- Search weather by city name
- Display current weather conditions
- Display a five-day weather forecast
- Convert temperatures between Celsius and Fahrenheit
- Loading and error messages
- Responsive layout for mobile and desktop
- Accessible form controls and keyboard navigation

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Open-Meteo Geocoding API
- Open-Meteo Weather Forecast API

## How to Run

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Enter a city name and search for its weather.

## API

Weather information is retrieved from [Open-Meteo](https://open-meteo.com/).
